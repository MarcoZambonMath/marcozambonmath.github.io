Useful resources

  • An advice sheet by Lauren Williams on postdoc applications.
  • A useful tex template to create multiple cover letters at once.
    - Download these two files: mycover.tex and mydata.tex.
    - Compile the mycover.tex file, and you will get multiple cover letters according to the data in the mydata.tex file (address,...).
