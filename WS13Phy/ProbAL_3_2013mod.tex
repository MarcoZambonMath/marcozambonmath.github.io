\n Sea $\mathcal{M}_{m\times n}(\mathbb{K})$ el conjunto de  matrices $m\times n$ sobre el
cuerpo $\mathbb{K} = \mathbb{R}$ ó $\mathbb{C}$. Comprobar que en $\mathcal{M}_{m\times n}(\mathbb{K})$
\begin{enumerate}\itemsep=-2pt
    \item La suma es asociativa.
    \item Cada matriz tiene un elemento
    opuesto (inverso aditivo).
    \item Sea $m=n$. Entonces el producto de matrices es distributivo (a derecha y a izquierda), con
    respecto a la suma de
    matrices.
\end{enumerate}

    \n
     Se dice que una matriz cuadrada es \textit{elemental} si se obtiene de la
    matriz identidad, haciendo alguna de las siguientes transformaciones:
    \begin{enumerate}\itemsep=-2pt
        \item [a)] Permutar dos filas.
        \item [b)] Sumarle a una fila otra distinta, multiplicada por un número.
        \item [c)] Multiplicar una fila por un número distinto de cero.
    \end{enumerate}

    \n Una matriz \textit{simétrica} (respectivamente, \textit{antisimétrica}) es aquella que cumple
    $A=A^T$ (respectivamente, $A={-}A^T$), siendo $A^T$ la matriz traspuesta de $A$.

    Probar
    que una matriz antisimétrica tiene nulos todos los elementos
    en la diagonal principal.

%    \n Una matriz que es a la vez simétrica y antisimétrica ha de ser la
%    matriz nula (todos sus elementos son 0).

    \n Probar que:
    \begin{enumerate}\itemsep=-2pt
        \item Dada una matriz cuadrada $A$, la matriz
        $1/2(A+A^T)$ es simétrica.
        \item Dada una matriz cuadrada $A$, la matriz
        $1/2(A-A^T)$ es antisimétrica.
        \item Toda matriz cuadrada se puede escribir como suma
        de una matriz simétrica y otra antisimétrica.
    \end{enumerate}
